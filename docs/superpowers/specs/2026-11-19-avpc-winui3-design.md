# AVPC WinUI 3 音视频播放控台设计规格

**日期：** 2026-11-19  
**状态：** 已经用户确认  
**目标平台：** Windows 11，C# / WinUI 3 / Windows App SDK

## 1. 目标

实现一个用于现场播放的双窗口音视频控台。控制台负责素材导入、方案编排、实时预览与正式播放控制；独立播放窗口在指定显示器全屏输出。界面采用 WinUI 3 原生控件和 Windows 11 Mica 材质。

## 2. 已确认的播放语义

- 一套方案包含 1 个必选视频、1 个可选独立音频。
- 未选择独立音频时使用视频原声；选择后静音视频原声，只播放独立音频。
- 视频与音频分别提供「循环」选项。
- 点击「开始正式播放」后播放第一套；播放中按钮变为「下一套」，每点击一次切换一套。
- 最后一套播放时再次点击「下一套」，停止视频与音频并回到空闲状态。
- 空闲时再次开始，从第一套重新播放。
- 非循环素材自然结束不会触发自动换套。

## 3. 界面布局

控制台采用 3 栏布局，底部控制栏固定：

1. **左侧素材库**：多选导入音视频、搜索、缩略图、时长、分辨率和帧率信息。
2. **中间预览台**：16:9 预览画面、播放／停止、进度、音量、当前方案名称。
3. **右侧方案队列**：方案从上到下排列，支持拖拽排序、新建、选择视频与音频、独立循环设置和结束行为设置。
4. **顶部屏幕选择**：分别选择控制台屏幕与正式输出屏幕。
5. **底部正式控制**：开始正式播放／下一套、停止输出、当前状态与方案进度。

素材列表隐藏文件名开头的长数字标识，完整文件名通过提示保留。方案较多时右侧独立滚动，底部控制保持可见。视觉原型保存在 `.superpowers/brainstorm/082d99c0d6e341b6bbf721bdc39a8e40/console-layout-v2.html`。

## 4. 预览行为

- 选中方案后可在控制台预览实际视频、独立音频、循环和结束行为。
- 预览使用独立播放实例，不改变正式播放的当前索引。
- 开始正式播放时停止预览并释放其声音，再从第一套开始。
- 正式播放期间不自动启动预览，避免双重发声。

## 5. 视频结束行为

每套方案的视频在关闭循环时可选择：

- **最后一帧**：自然结束后定格最后画面。
- **淡出**：从视频结尾前 2 秒开始将画面逐渐降至黑色，结束后保持黑屏；视频不足 2 秒时从起始位置开始淡出。

循环开启时不执行结束行为。音频是否结束不影响视频画面，也不会触发换套。

## 6. 组件与职责

### 6.1 控制台窗口

只负责展示和收集操作，通过播放协调器执行预览、开始、下一套与停止，不直接持有正式播放器状态。

### 6.2 正式播放窗口

独立无边框全屏窗口，包含视频画面与黑色覆盖层。覆盖层用于淡出结束效果；空闲或发生播放错误时显示黑屏。

### 6.3 播放协调器

统一维护方案队列、当前索引和空闲／播放状态，管理预览与正式输出的视频、音频播放器。外部音频启用时负责静音视频原声，切套和停止时清理上一组播放实例。

### 6.4 屏幕管理器

枚举可用显示器并移动窗口。默认控制台位于副屏、正式输出位于主屏；仅有一个显示器时两者使用同一显示器，并允许用户调整。

### 6.5 核心状态模型

`MediaAsset` 表示素材路径、类型和显示信息；`PlaybackScheme` 表示视频、可选音频、2 个循环选项与视频结束行为；`PlaybackQueue` 表示有序方案和正式播放索引。核心状态转换不依赖 WinUI，便于自动测试。

## 7. 数据流

1. 用户导入素材，应用读取媒体属性并加入素材库。
2. 用户将素材分配到方案并调整顺序、循环和结束行为。
3. 预览操作读取当前选中方案，但不修改正式播放索引。
4. 正式播放操作读取队列顺序，由协调器同步切换视频与音频。
5. 播放器状态与错误回传控制台，更新进度、按钮文字和提示。

本版本的数据保存在本次运行内，不加入账号、云同步或其他未要求的素材管理功能。

## 8. 错误处理

- 开始正式播放前验证方案是否存在视频以及文件是否可访问，错误在控制台明确指出。
- 文件在播放中丢失或解码失败时，正式窗口保持黑屏，控制台显示错误并允许停止或进入下一套。
- 当前素材使用 HEVC 编码；系统缺少解码支持时显示可理解的提示，不让应用崩溃。
- 所选显示器不可用时回退到可用主屏，并在控制台提示。

## 9. 验证标准

### 自动测试

- 首次开始进入第一套，连续点击按排序后的队列切换。
- 最后一套之后停止，再次开始回到第一套。
- 拖拽排序改变正式播放顺序。
- 视频和音频循环状态彼此独立。
- 外部音频存在时视频原声静音，不存在时使用原声。
- 循环视频不执行结束行为；非循环视频支持最后一帧和最后 2 秒淡出。
- 预览和停止预览不改变正式播放索引。

### 构建与集成验证

- `dotnet test` 全部通过。
- `dotnet build` 无错误。
- 使用 `素材库` 中 4 段 MP4 和 2 首 MP3 验证导入、预览与正式播放。
- 在双屏环境验证控制台和输出窗口的位置、换套、停止及音频互斥。
- 验证 4 段实际素材均为 2560×1440、16:9；预览和正式输出保持画面比例。

## 10. 不在本次范围

- 视频剪辑、转码、滤镜与多画面合成。
- 一套方案中叠加多个视频或多个音频。
- 素材自然结束后自动换套。
- 网络流、在线素材库和远程控制。
