# 方案卡片直接播放设计

日期：2026-11-20

## 目标

在每套方案卡片右上角提供三角形播放按钮，使任意方案可以直接成为正式输出内容。

## 行为

- 展示窗口未开启：点击卡片播放按钮后自动开启展示窗口，并从头播放该方案，不显示确认框。
- 展示窗口已开启：无论正在播放、暂停或黑屏等待，都显示包含“切换”和“取消”的确认框。
- 确认切换：停止当前方案的画面、音频、计时和淡出，从头播放目标方案；目标方案成为当前队列索引，后续上一套/下一套以它为基准。
- 取消切换：不改变当前窗口、方案索引或播放/暂停状态。
- 点击同一当前方案也按上述规则确认并从头重新播放。
- 卡片按钮不影响方案选择、行内重命名、拖放替换和拖拽排序。

## 实现范围

- `PlaybackQueue` 增加按索引选择当前方案的方法，并覆盖正常跳转、顺序衔接和无效索引测试。
- `MainWindow.xaml` 在卡片标题区右侧添加播放按钮，保留排序提示空间。
- `MainWindow.xaml.cs` 使用 `ContentDialog` 确认，并复用 `PlayOutputScheme` 完成窗口创建、预览停止、旧内容停止和目标方案播放。
- 不修改预览、持久化模型、素材库或方案编辑行为。

## 验证

1. 指定索引测试先失败，再以最少实现通过。
2. `dotnet test AVPC.sln` 全部通过。
3. `dotnet build AVPC.sln` 和 `dotnet build src/AVPC/AVPC.csproj` 均为 0 错误。
4. 用户手动检查卡片布局、未开展示直接播放、已开展示确认/取消、切换后前后顺序，以及实际双屏、声音和视觉效果。
