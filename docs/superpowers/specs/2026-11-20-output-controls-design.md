# 正式输出控制调整设计

日期：2026-11-20

## 目标

简化主控台的屏幕选择与正式输出控制：

- 右上角只保留一个屏幕下拉框，前置文字为“展示屏:”。
- 下拉框选中项是正式播放的输出屏幕。
- 初始不显示“停止输出”，成功开始正式播放后才显示。
- 底栏在“停止输出”左侧增加“结束”按钮；点击后停止正式播放并关闭输出窗口，主控台保持运行。

## 范围与现状

只修改 `src/AVPC/MainWindow.xaml` 和 `src/AVPC/MainWindow.xaml.cs`，沿用现有 `PlaybackQueue`、`PlaybackCoordinator` 与 `PlaybackWindow` 状态流，不新增状态类或 ViewModel，不改变素材、方案、预览及持久化模型。

主控台启动时仍由 `App.OnLaunched` 自动选择控制台所在显示器；移除右上角控制台屏幕下拉框后，不提供手动移动主控台的替代入口。

## 界面与行为

### 展示屏选择

- 删除 `ConsoleDisplaySelector` 及其 `ConsoleDisplayChanged` 事件处理。
- 保留 `OutputDisplaySelector`，与“展示屏:”文字组成水平区域，放在右上角。
- 保留现有默认选择：优先主屏，没有主屏时选择第一块屏幕。
- 保留现有 `OutputDisplayChanged` 行为：输出窗口已存在时，切换选中屏幕会将窗口移动到新的全屏目标。

### 停止输出

- 为现有停止按钮添加名称，初始 `Visibility="Collapsed"`。
- 仅在 `_coordinator.Play(scheme)` 成功执行后显示，避免校验或启动失败时错误显示。
- 点击“停止输出”后，沿用现有逻辑：停止队列与媒体、清空输出画面、保存工作区、复位播放按钮和模式文字，然后隐藏停止按钮；输出窗口保持打开。
- 最后一套之后再次点击“下一套”时，沿用现有自然停止逻辑，并隐藏停止按钮。

### 结束

- “结束”按钮始终显示在底栏，位于“停止输出”左侧。
- 点击后停止队列和协调器、复位正式播放界面状态并隐藏停止按钮。
- 随后关闭 `_outputWindow`，将 `_outputWindow` 和 `_coordinator` 置空；下次正式播放由 `EnsureOutputWindow` 重新创建。
- 不关闭主控台，不退出应用，不改变预览和方案数据。

## 异常与边界

- 正式播放校验失败或 `_coordinator.Play` 抛出异常时，保持现有错误提示，不显示停止按钮。
- 未创建输出窗口时点击“结束”，只复位输出状态，不执行窗口关闭。
- 输出窗口已经停止但尚未关闭时，“结束”仍可关闭该窗口。
