# 正式输出倍速控制设计

日期：2026-11-20

## 目标

在“开启展示”左侧增加倍速下拉框，选项为 ×1、×2、×5、×10、×20，默认 ×1。

## 行为

- 倍率同时作用于正式输出的视频和独立音频。
- 展示中切换倍率立即更新当前播放器，不重启媒体、不改变播放位置。
- 后续切换方案、暂停后恢复、结束再开启展示均保留当前倍率。
- 图片停留时间、预览播放和工作区持久化内容不变。

## 实现

- `MainWindow.xaml` 增加下拉框及五个固定选项。
- `MainWindow.xaml.cs` 将选中倍率传给现有 `PlaybackCoordinator`，新建协调器时同步当前倍率。
- `PlaybackCoordinator` 保存倍率，更新当前视频/音频的 `PlaybackSession.PlaybackRate`，并在创建后续播放器时应用。

## 验证

运行全部自动测试、解决方案构建和启动项目构建。由用户手动验证五档倍率对当前及后续音视频的实际效果，以及暂停恢复、方案切换后的倍率保持；高倍速是否受解码器或硬件限制需实际检查。
